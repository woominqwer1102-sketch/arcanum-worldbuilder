# 아르카눔 (Arcanum) · 판타지 세계관 노트

소설·웹툰용 판타지 세계관을 **아이폰 한 손으로** 짓는 웹앱(PWA)입니다.
인물 카드, 인터랙티브 관계도, 연표, 지도 핀, 설정집, 에피소드 콘티, 그리고
이름·지명 생성기와 스토리 여정 타임라인까지 — 입력한 모든 것은 기기 안에만 저장됩니다.

---

## 바로 열어 보기

| 방법 | 여는 법 | 특징 |
| --- | --- | --- |
| **앱처럼 설치 (권장)** | 폴더를 로컬 서버로 띄우거나 웹에 올린 뒤 Safari에서 열고 `공유 → 홈 화면에 추가` | 전체 화면, 오프라인 캐시, 앱 아이콘 |
| **단일 파일** | `worldbuilder-standalone.html` 하나만 폰(파일 앱)에 넣고 Safari로 열기 | CSS·JS·아이콘이 모두 한 파일, 서버 불필요 |
| 데스크톱 미리보기 | 아래 로컬 서버 명령 후 브라우저에서 `http://localhost:8080` | 개발·검수용 |

```bash
cd worldbuilder-app
python3 -m http.server 8080
# Safari/Chrome에서 http://localhost:8080 접속
```

> 단일 파일을 다시 만들려면: `python3 build_standalone.py`
> (index.html + styles.css + js/*.js + 아이콘을 순서대로 인라인합니다.)

### 홈 화면에 추가하기 (iPhone)
1. Safari로 앱을 연다.
2. 하단 `공유` 버튼 → **홈 화면에 추가**.
3. 이름을 `아르카눔`으로 두고 추가하면 상태바까지 꽉 찬 앱 화면으로 열립니다.
4. 한 번 열어 두면 서비스 워커가 앱을 캐시해 **인터넷 없이도** 실행됩니다.

## 무엇을 할 수 있나

### 1. 다중 세계관 + 대시보드
- 세계관을 여러 개 만들어 오가며 씁니다. 상단 세계관 이름을 누르면 전환/추가/편집/삭제.
- 첫 실행에는 **‘아르카디아 연대기’** 샘플이 들어 있어, 모든 기능을 바로 눌러 볼 수 있습니다.
- 대시보드에서 인물·관계·사건·지역·설정·에피소드 수를 한눈에 보고, 바로 쓰기 타일로 이동합니다.

### 2. 인물 카드
- 이름, 칭호/별명, 종족, 소속/세력, 나이·신체, 능력/무기, 성격·배경 메모, 대표 이미지.
- 사진은 폰 사진첩에서 고르면 **자동 리사이즈·압축(JPEG)** 후 저장됩니다.
- **✨ AI 일러스트 생성**: 인물 폼의 버튼 한 번으로 이름·칭호·종족·소속·나이·능력·성격 메모를 조합한 **영어 판타지 프롬프트**를 만들고, 무료 공개 AI 이미지로 초상화를 받아 대표 이미지에 자동 적용합니다. 서버·CORS·시간 초과로 실패하면 앱은 멈추지 않고 프롬프트 원클릭 복사와 **문장(紋章) 실루엣 초상화** 폴백을 제공합니다.
- 소속/종족 칩 필터 + **등급 필터** + 이름·칭호·종족·메모 실시간 검색.
- 카드를 누르면 상세 시트: 등급 배지, 관계 목록, 등장 사건·에피소드까지 한 번에.

### 3. 인물 관계도 (SVG)
- **인물 관계도 | 세력 관계도** 세그먼트. 세력 관계도는 설정집의 `세력·국가` 항목을 노드로, `world.factionRelations`(동맹·적대·경쟁·종속·교역·협정)를 선으로 그립니다. 노드 드래그·핀치 줌·관계 잇기·편집 모두 저장/백업에 포함됩니다.
- 관계 유형은 동맹·적대·가족·연인·**스승**·**제자**·라이벌·기타로 구분됩니다.
- 노드를 **끌어서 이동**, 두 손가락으로 **확대/축소**, 빈 곳을 끌면 이동.
- `관계 추가` → 인물 두 명을 차례로 탭 → 관계 종류(동맹·적대·가족·연인·스승·제자·라이벌·기타)와 한 줄 설명·메모 저장.
- 관계 종류마다 색이 다르고, 적대는 점선으로 그려집니다. 선을 탭하면 수정/삭제.
- 노드 위치는 자동 저장됩니다.

### 4. 연표
- 세계관마다 **대표 역법(eraPrefix, 예: 제국력)** 과 현재 연도를 정해 두면 사건에 자동으로 붙습니다.
- 연도는 숫자 입력 + `−100 / −10 / − / + / +10 / +100` 스텝퍼로 조절해 `제국력 104년`처럼 표시·저장됩니다.
- 시대 순서 → 연도 숫자(yearNum) 오름차순으로 **자동 정렬**, 시대 칩으로 필터.

### 5. 지도 + 지역 핀 + 지형
- 기본 판타지 지도(SVG)가 들어 있고, 직접 그린 지도를 이미지로 올릴 수도 있습니다.
- **지도 비율 자동 맞춤(자유 비율)**: 올린 이미지의 실제 가로·세로 비율을 그대로 씁니다. 파노라마·정사각형·세로형 어떤 지도도 잘리지 않고, 핀·지형 스탬프·스토리 여정 좌표도 이미지 위에 1:1로 맞습니다.
- **확대 · 이동**: 두 손가락 핀치 줌, 확대 상태에서 한 손가락 팬, 오른쪽 아래 `+` / `100%(맞춤)` / `−`. 확대해도 핀·지형을 놓는 좌표는 화면 → 지도 %로 정확히 역산됩니다.
- **자동 양피지 변환**: 지도를 올리면 Canvas로 옛날 양피지 질감(종이 입자·얼룩·주름·비네팅)과 세피아 잉크를 입혀 저장합니다. 툴바의 `📜 양피지 / 🖼️ 원본` 으로 언제든 전환.
- **🎲 대륙 생성**: 지구 대륙 윤곽을 회전·반전·확대해 섞고 프랙탈 해안선을 입힌 판타지 세계지도를 한 번에 만듭니다. 누를 때마다 새 대륙이 나오고, 그 위에 바로 핀·지형을 얹을 수 있습니다.
- `핀 꽂기` → 지도를 탭하면 그 자리에 핀. 지역명·유형·기후·지배 세력·특산물·위험 요소·메모.
- **⛰️ 지형 꾸미기**: 지형 팔레트(산맥·구릉·숲·늪·강·호수·바다·사막·화산·설원·성·도시·유적·던전·길·항로)에서 골라 지도를 터치하면 판타지풍 SVG 스탬프가 얹힙니다. 크기 소/중/대, 놓인 스탬프를 탭해 하나씩 삭제, 전체 지우기, 자동 저장·JSON 백업 포함.
- 핀을 탭하면 지역 상세. 지역 목록에서도 열 수 있습니다.

### 6. 스토리 여정 (지도 타임라인)
- 지도 툴바의 **`스토리 여정`** 을 누르면, 에피소드(또는 연표 사건)에 연결된 지역을 **순서대로 잇는 금빛 점선 경로**가 그려집니다.
- ①②③ 순서 배지, 현재 단계 핀 발광·확대, 지나온 경로 강조.
- 지도 아래 컨트롤러에서 **◀ 이전 / 다음 ▶**, **단계 슬라이더**, **자동 재생** — 한 손 엄지 위치에 있습니다.
- 컨트롤러 카드에 화수·지역·제목·시놉시스·등장인물이 함께 표시됩니다.
- 샘플 세계관은 1~3화에 지역이 연결되어 있어 첫 실행에서 바로 체험할 수 있습니다.

### 7. 설정집 (Codex)
- 분류(마법·능력체계 / 세력·국가 / 종족·몬스터 / 아이템·유물 / 기타 규칙), 제목, 본문, 태그.
- 분류 칩 + 키워드 검색, 카드 접기/펼치기.
- **⚔️ 능력·등급** 세그먼트: 강함·등급 체계 목록과 편집(설명 · 1~15단계 · 단계별 이름)을 설정집 안에서 바로 합니다.
- 인물의 **종족·소속·능력·무기는 설정집 항목에서만 골라** 연결됩니다(설정집에서 이름을 고치면 인물 표시도 함께 바뀝니다). 없는 항목은 `+ 설정집에 새 항목 추가`로 바로 등록.

### 8. 에피소드 · 콘티 메모
- 화수, 제목, 상태(아이디어/집필중/완료), 시놉시스, 등장인물·배경 지역 연결, 씬별 제목·메모.
- 다음 화수는 자동 제안됩니다.

### 9. 이름 · 지명 생성기 (✨)
- 인물: **서양 정통 판타지 / 동양 무협·선협 / 북유럽·아케인 / 고대 신화·이국** 스타일, `칭호·이명 함께` 토글, 8개씩 추천, 다시 뽑기, 복사.
- 지명: **왕국·제국 / 도시·항구 / 숲·산맥·유적 / 던전·길드·여관 / 동양풍** 유형별 추천.
- 인물 폼의 `✨ 이름 추천`, 지역 폼의 `✨ 지명 추천` 버튼으로 **이름 칸에 바로 넣기**(추천된 이명은 비어 있는 칭호 칸에 자동으로).
- 상단 ✨ 버튼이나 더보기 → `이름·지명 추천`에서 언제든 단독으로 열 수 있습니다.

### 10. 저장 · 백업 · 테마
- 모든 변경은 **IndexedDB(이미지 포함) + localStorage 미러**에 자동 저장.
- 더보기 → `백업·복원`: JSON 내보내기, 가져오기(전체 교체 또는 기존 세계관 유지하고 추가). 파일명은 `세계_만들기_아르카눔_백업.json` **고정**이라 같은 폴더에 다시 저장할 때 iOS의 **[대치]** 로 덮어쓸 수 있습니다(날짜 붙여 별도 저장 옵션도 있음).
- **아이폰 파일 앱 폴더 저장**: 내보내기 버튼이 iOS 공유 시트(Web Share API)를 열어 `파일에 저장 → '세계 만들기' 폴더`를 고를 수 있습니다. 공유를 지원하지 않는 환경에서는 `세계_만들기_아르카눔_백업_YYYYMMDD.json` 다운로드로 자동 폴백합니다. 기본 폴더명은 백업 화면에서 바꿀 수 있습니다.
- 테마: **다크 아케인**(기본) ↔ **라이트 양피지** 전환. 선택은 다음 실행에도 유지.

### 11. 강함 · 등급 체계 (Power Tier)
- 더보기 → `강함 · 등급 체계`(또는 인물 화면의 `등급`)에서 세계관마다 여러 체계를 등록·수정·삭제합니다. 예: `마법 서클`, `기사단 계위`, `모험가 랭크`.
- 체계마다 이름, 아이콘(⚔·✦ 등), 색상, 그리고 단계를 정합니다. **단위(예: 서클) + 개수(1~20) → [자동 생성]** 으로 `1서클`~`9서클`이 한 번에 만들어지고, 각 단계 이름은 개별 수정·추가·삭제할 수 있습니다.
- 인물 폼의 **강함 / 등급**에서 체계별 단계 버튼을 탭 한 번으로 선택(여러 체계 동시 보유 가능, 예: 마법 4서클 + 기사단 기사장). 먼저 고른 등급이 대표로 표시됩니다.
- 인물 카드·상세 시트에 체계 색의 판타지 배지로 표시되고, 인물 목록의 **등급 필터**로 `체계 · 단계`를 골라 찾을 수 있습니다.
- 데이터는 `world.rankSystems`(체계) + `character.ranks`(체계별 단계 인덱스)로 저장되어 백업 JSON에 그대로 담깁니다. 샘플 세계관에는 `마법 서클(1~9서클)`·`기사단 계위(수습~그랜드마스터 6단계)`가 기본으로 들어 있고 인물들에게 연결되어 있습니다.

## 데이터와 개인정보
- 서버로 아무것도 보내지 않습니다. 사진·글·세계관은 브라우저 저장소에만 남습니다.
- 브라우저 데이터를 지우면 함께 사라지므로, 가끔 **백업 내보내기**로 JSON을 보관하세요.
- 백업 파일에는 인물 사진·지도 이미지가 data URL로 함께 들어갑니다.

## 파일 구조
```
worldbuilder-app/
├─ index.html                  앱 셸 (아이콘 스프라이트 포함)
├─ styles.css                  다크 아케인 / 양피지 테마, 390~430px 모바일 퍼스트
├─ js/
│  ├─ utils.js                 DOM·바텀시트·토스트·이미지 압축·파일 유틸
│  ├─ store.js                 IndexedDB + localStorage 저장, 가져오기/내보내기
│  ├─ generator.js             이름·지명 생성기 + AI 초상 프롬프트·폴백 초상화
│  ├─ sample.js                샘플 세계관(등급 체계 포함) + 벡터 판타지 지도(SVG)
│  ├─ graph.js                 관계도 (SVG 드래그·줌·관계선)
│  ├─ mapview.js               지도 비율·지형 스탬프 + 핀 + 스토리 여정 재생
│  └─ app.js                   화면·폼·백업·네비게이션
├─ manifest.json               PWA 매니페스트
├─ sw.js                       오프라인 캐시 서비스 워커
├─ icons/                      180·192·512·maskable 아이콘
├─ build_standalone.py         단일 파일 빌드 스크립트
└─ worldbuilder-standalone.html  ← 폰에서 바로 열 수 있는 단일 실행 파일
```
