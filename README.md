# 아르카눔 (Arcanum) · 판타지 세계관 노트

소설·웹툰용 판타지 세계관을 **아이폰 한 손으로** 짓는 웹앱(PWA)입니다.
인물 카드, 인터랙티브 관계도, 연표, 지도 핀, 설정집, 에피소드 콘티, 그리고
이름·지명 생성기와 스토리 여정 타임라인까지 — 입력한 모든 것은 기기 안에만 저장됩니다.

---

## 바로 열어 보기

| 방법 | 여는 법 | 특징 |
| --- | --- | --- |
| **앱처럼 설치 (권장)** | 폴더를 로컬 서버로 띄우거나 웹에 올린 뒤 Safari에서 열고 `공유 → 홈 화면에 추가` | 전체 화면, 오프라인 캐시, 앱 아이콘 |
| **단일 파일** | `worldbuilder-standalone.html` 하나만 폰(파일 앱)에 넣고 Safari로 열기 | CSS·JS·아이콘이 모두 한 파일, 서버 불필요 |
| 데스크톱 미리보기 | 아래 로컬 서버 명령 후 브라우저에서 `http://localhost:8080` | 개발·검수용 |

```bash
cd worldbuilder-app
python3 -m http.server 8080
# Safari/Chrome에서 http://localhost:8080 접속
```

> 단일 파일을 다시 만들려면: `python3 build_standalone.py`
> (index.html + styles.css + js/*.js + 아이콘을 순서대로 인라인합니다.)

### 홈 화면에 추가하기 (iPhone)
1. Safari로 앱을 연다.
2. 하단 `공유` 버튼 → **홈 화면에 추가**.
3. 이름을 `아르카눔`으로 두고 추가하면 상태바까지 꽉 찬 앱 화면으로 열립니다.
4. 한 번 열어 두면 서비스 워커가 앱을 캐시해 **인터넷 없이도** 실행됩니다.

## 무엇을 할 수 있나

### 1. 다중 세계관 + 대시보드
- 세계관을 여러 개 만들어 오가며 씁니다. 상단 세계관 이름을 누르면 전환/추가/편집/삭제.
- 첫 실행에는 **‘아르카디아 연대기’** 샘플이 들어 있어, 모든 기능을 바로 눌러 볼 수 있습니다.
- 대시보드에서 인물·관계·사건·지역·설정·에피소드 수를 한눈에 보고, 바로 쓰기 타일로 이동합니다.

### 2. 인물 카드
- 이름, 칭호/별명, 종족, 소속/세력, 나이·신체, 능력/무기, 성격·배경 메모, 대표 이미지.
- 사진은 폰 사진첩에서 고르면 **자동 리사이즈·압축(JPEG)** 후 저장됩니다.
- 소속/종족 칩 필터 + 이름·칭호·종족·메모 실시간 검색.
- 카드를 누르면 상세 시트: 관계 목록, 등장 사건·에피소드까지 한 번에.

### 3. 인물 관계도 (SVG)
- 노드를 **끌어서 이동**, 두 손가락으로 **확대/축소**, 빈 곳을 끌면 이동.
- `관계 추가` → 인물 두 명을 차례로 탭 → 관계 종류(동맹·적대·가족·연인·스승·제자·라이벌·기타)와 한 줄 설명·메모 저장.
- 관계 종류마다 색이 다르고, 적대는 점선으로 그려집니다. 선을 탭하면 수정/삭제.
- 노드 위치는 자동 저장됩니다.

### 4. 연표
- 시대(예: 제3기) + 연도 + 제목 + 요약 + 상세 + 관련 인물·지역 태그.
- 시대 순서 → 연도 순으로 **자동 정렬**, 시대 칩으로 필터.

### 5. 지도 + 지역 핀
- 기본 판타지 지도(SVG)가 들어 있고, 직접 그린 지도를 이미지로 올릴 수도 있습니다.
- `핀 꽂기` → 지도를 탭하면 그 자리에 핀. 지역명·유형·기후·지배 세력·특산물·위험 요소·메모.
- 핀을 탭하면 지역 상세. 지역 목록에서도 열 수 있습니다.

### 6. 스토리 여정 (지도 타임라인)
- 지도 툴바의 **`스토리 여정`** 을 누르면, 에피소드(또는 연표 사건)에 연결된 지역을 **순서대로 잇는 금빛 점선 경로**가 그려집니다.
- ①②③ 순서 배지, 현재 단계 핀 발광·확대, 지나온 경로 강조.
- 지도 아래 컨트롤러에서 **◀ 이전 / 다음 ▶**, **단계 슬라이더**, **자동 재생** — 한 손 엄지 위치에 있습니다.
- 컨트롤러 카드에 화수·지역·제목·시놉시스·등장인물이 함께 표시됩니다.
- 샘플 세계관은 1~3화에 지역이 연결되어 있어 첫 실행에서 바로 체험할 수 있습니다.

### 7. 설정집 (Codex)
- 분류(마법·능력체계 / 세력·국가 / 종족·몬스터 / 아이템·유물 / 기타 규칙), 제목, 본문, 태그.
- 분류 칩 + 키워드 검색, 카드 접기/펼치기.

### 8. 에피소드 · 콘티 메모
- 화수, 제목, 상태(아이디어/집필중/완료), 시놉시스, 등장인물·배경 지역 연결, 씬별 제목·메모.
- 다음 화수는 자동 제안됩니다.

### 9. 이름 · 지명 생성기 (✨)
- 인물: **서양 정통 판타지 / 동양 무협·선협 / 북유럽·아케인 / 고대 신화·이국** 스타일, `칭호·이명 함께` 토글, 8개씩 추천, 다시 뽑기, 복사.
- 지명: **왕국·제국 / 도시·항구 / 숲·산맥·유적 / 던전·길드·여관 / 동양풍** 유형별 추천.
- 인물 폼의 `✨ 이름 추천`, 지역 폼의 `✨ 지명 추천` 버튼으로 **이름 칸에 바로 넣기**(추천된 이명은 비어 있는 칭호 칸에 자동으로).
- 상단 ✨ 버튼이나 더보기 → `이름·지명 추천`에서 언제든 단독으로 열 수 있습니다.

### 10. 저장 · 백업 · 테마
- 모든 변경은 **IndexedDB(이미지 포함) + localStorage 미러**에 자동 저장.
- 더보기 → `백업·복원`: JSON 내보내기, 가져오기(전체 교체 또는 기존 세계관 유지하고 추가).
- 테마: **다크 아케인**(기본) ↔ **라이트 양피지** 전환. 선택은 다음 실행에도 유지.

## 데이터와 개인정보
- 서버로 아무것도 보내지 않습니다. 사진·글·세계관은 브라우저 저장소에만 남습니다.
- 브라우저 데이터를 지우면 함께 사라지므로, 가끔 **백업 내보내기**로 JSON을 보관하세요.
- 백업 파일에는 인물 사진·지도 이미지가 data URL로 함께 들어갑니다.

## 파일 구조
```
worldbuilder-app/
├─ index.html                  앱 셸 (아이콘 스프라이트 포함)
├─ styles.css                  다크 아케인 / 양피지 테마, 390~430px 모바일 퍼스트
├─ js/
│  ├─ utils.js                 DOM·바텀시트·토스트·이미지 압축·파일 유틸
│  ├─ store.js                 IndexedDB + localStorage 저장, 가져오기/내보내기
│  ├─ generator.js             이름·지명 생성기 (스타일별 어휘 조합)
│  ├─ sample.js                샘플 세계관 + 벡터 판타지 지도(SVG)
│  ├─ graph.js                 관계도 (SVG 드래그·줌·관계선)
│  ├─ mapview.js               지도 핀 + 스토리 여정 재생
│  └─ app.js                   화면·폼·백업·네비게이션
├─ manifest.json               PWA 매니페스트
├─ sw.js                       오프라인 캐시 서비스 워커
├─ icons/                      180·192·512·maskable 아이콘
├─ build_standalone.py         단일 파일 빌드 스크립트
└─ worldbuilder-standalone.html  ← 폰에서 바로 열 수 있는 단일 실행 파일
```
